- [ ] **步骤 1：spike/CMakeLists.txt**

```cmake
# M13 集成 spike：ZzRenderView 契约的 Qt 前端可行性验证（独立工程，不进主构建）。
cmake_minimum_required(VERSION 3.25)
project(zzcore_spike CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

set(ZZTERMCORE_SOURCE_DIR "${CMAKE_CURRENT_SOURCE_DIR}/../../ZzTermCore"
    CACHE PATH "ZzTermCore 源码目录（add_subdirectory 消费）")

find_package(Qt6 REQUIRED COMPONENTS Widgets Test)
qt_standard_project_setup()

# ZzTermCore：静态消费显式 contour OFF（M13 前置批实证的静态链接约束）；
# 只用 native 后端，关闭其测试以加速。
set(ZZTERM_WITH_CONTOUR OFF CACHE BOOL "" FORCE)
set(ZZTERM_BUILD_TESTS OFF CACHE BOOL "" FORCE)
add_subdirectory("${ZZTERMCORE_SOURCE_DIR}" zztermcore EXCLUDE_FROM_ALL)

qt_add_executable(zzcore_spike main.cpp ZzCoreViewWidget.h ZzCoreViewWidget.cpp)
target_link_libraries(zzcore_spike PRIVATE Qt6::Widgets ZzTerm::ZzTermCore ZzTerm::Pty)

enable_testing()
add_subdirectory(tests)
```

- [ ] **步骤 2：ZzCoreViewWidget（产物，可复用标准）**

职责与形态（Doxygen 中文注释，遵 ZzClawTerm 仓 AGENTS 约定）：
- 持有 `ZzTerminal term_;`（构造 80x24、Native、历史 10000）与 `std::function<void(std::string)> writeFn_;`（设回调 setter）。
- `feedForTest(std::string_view)` 公开件：feed + update（QTest 与宿主共用入口；宿主的数据回调也走它，单一 feed 路径）。
- paintEvent：QFontDatabase::systemFont(FixedFont) 等宽字体，QFontMetrics 定格宽格高；按 renderView() 的 size() 逐行 lineAt(row)，逐格 cellAt(col).text 画 drawText（spike 全量重绘，无增量无配色——背景默认、文本默认色；光标以 cursor() 位置画反色矩形）。
- keyPressEvent：Qt 键事件映射 ZzKeyEvent（可打印文本走 encodeText；回车/方向/退格/Tab/Escape/Ctrl 组合走 encodeKey——映射表为本 widget 的职责，ZzKeyEvent::Key 枚举对齐 Input.h:78），结果经 writeFn_ 写出。
- resizeEvent：按格宽格高换算行列，调 term_.resize(cols, rows)。
- 历史滚动：先查 ZzTerminal 公开 API 的历史访问件（Terminal.h/Scrollback.h）；有才实现 QScrollArea 式偏移滚动，没有则跳过并记入报告（API 缺口预登记项）。

- [ ] **步骤 3：main.cpp（弃子宿主）**

- 解析参数：`--local`（默认）/ `--ssh <host> [user]`。
- `--local`：`ZzPtyConfig{"bash"}` spawn（Unix 直接可用；Windows 本 spike 不验），QSocketNotifier(masterFd, Read) 回调：pty->read 循环到 EAGAIN，字节经 widget.feedForTest；widget writeFn_ 设为 pty->writeAll 转发。widget 的 resize 变化经 ZzPty::resize 转发（widget 发信号或 main 轮询尺寸变化——spike 以 resizeEvent 同步调用即可）。
- `--ssh`：直驱 ZzSshCore——参照 ZzClawTerm 的 src/transport/ZzSshTransport.cpp 的连接建立序列（ZzSshConnection 连接 + 认证（当前用户 agent/key 优先，密码提示兜底）+ createShellChannel），channel 读回调 feed、writeFn_ 写 channel、尺寸变化转发 window-change。ZzSshCore 头文件在其 third_party/ZzSshCore/src/，链接目标名读其 CMakeLists 确认。
- 窗口标题标注当前模式（spike-local / spike-ssh 加主机名）。

- [ ] **步骤 4：QTest（offscreen）**

tests/tst_spikerender.cpp：

- case 2（PTY 链路）：ZzPty spawn cat，writeAll 写标记，轮询（QTRY_VERIFY_WITH_TIMEOUT 5s）断言 widget 文本含标记——经 feedForTest 喂入，验证 字节流->feed->渲染 全链。
