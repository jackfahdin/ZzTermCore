- [ ] **步骤 1：pty/windows/ZzPty.cpp 实现**

骨架（约 250 行；Win32 API 细节以 consoleapi.h 与 Microsoft Learn 为准，实现期自查）：

```cpp
// ZzPty Windows 实现：ConPTY（CreatePseudoConsole + 匿名管道 + CreateProcessW）。
// 最低系统要求 Windows 10 1809（规格 4A：旧系统 spawn 返回 nullptr，GetLastError 留诊断）。
#include "ZzPty.h"

#if defined(_WIN32)

#include <string>

#ifndef WIN32_LEAN_AND_MEAN
#define WIN32_LEAN_AND_MEAN
#endif
#include <windows.h>
#include <consoleapi.h> // CreatePseudoConsole / ResizePseudoConsole / ClosePseudoConsole

// spawn：argv 拼接为命令行（引号转义规则同 CommandLineToArgvW），UTF-8 -> UTF-16 转换；
// CreatePipe 双管（安全属性可继承）-> CreatePseudoConsole(COORD, inRead, outWrite, 0, &hpcon)
// -> InitializeProcThreadAttributeList（先查尺寸再分配）-> UpdateProcThreadAttribute(
// PROC_THREAD_ATTRIBUTE_PSEUDOCONSOLE) -> CreateProcessW(EXTENDED_STARTUPINFO_PRESENT)
// -> 关闭子进程侧句柄端（inRead/outWrite 与属性列表）。
// 任一环节失败：按已得资源逆序清理，返回 nullptr（GetLastError 保留）。
//
// read：ReadFile；子进程退出且管道排空后归一 EOF 返回 0；PeekNamedPipe 查无数据时
// 返回 -1（调用方语义等价 Unix EAGAIN——具体错误指示形态以实现注释与 test_pty 断言为准）。
//
// writeAll：WriteFile 循环至写完（处理部分写入）。
//
// resize：COORD{cols, rows} -> ResizePseudoConsole；参数 <=0 返回 false。
//
// tryWait：GetExitCodeProcess——STILL_ACTIVE 归一 nullopt；已退出缓存退出码，
// 重复调用返回同值（与 Unix 版 reaped_/exitCode_ 语义一致）。
//
// 析构：ClosePseudoConsole -> 等短暂宽限 -> TerminateProcess 兜底 -> 关全部句柄
// -> GetExitCodeProcess 收尾（不遗留僵尸等价物）。
#endif
```

实现注意：所有公共方法的 noexcept 与返回值语义严格对齐 pty/ZzPty.h 注释；HPCON/HANDLE 以 void* 出入公开头（头文件不含 windows.h——Windows 实现文件内部包含，调用方包含 ZzPty.h 不引入 windows.h 污染）。

- [ ] **步骤 2：test_pty.cpp 全平台化**

守卫 `#if defined(__unix__) || defined(__APPLE__)` 改为 `#if 1` 即全平台（删除守卫与 else 平凡 main），文件内按平台分支：
- 公共件：ZZ_TEST_EXPECT 宏、g_failures、readAll/readWithTimeout 双平台实现（Windows 段用 PeekNamedPipe + Sleep 轮询替代 poll）。
- testCatRoundTrip：Unix 用 cat；Windows 用 cmd.exe 的 findstr "^"（逐行回显 stdin）；断言同形态（写入什么读回什么，注意 Windows 行尾为 CRLF——预期串按平台构造）。
- testResize：Unix 原样（ioctl 回读）；Windows 仅断言 resize 返回 true（ConPTY 无尺寸回读 API，注释注明）。
- testExitCode：Unix 原样（sh -c exit 42）；Windows 用 cmd /c exit 42，断言退出码 42。
- testSpawnFailure：双平台同断言（不存在程序名，spawn 返回 nullptr 且不崩溃；Unix 断言 errno 非 0，Windows 断言 GetLastError 非 0）。
