# M7b T2：contour 聚簇行为探针结果与 parity 裁定表

> 探针程序：tests/probe/cluster_probe.cpp（不注册 ctest），只用 Contour 后端
> ZzTerminal(80, 24, Contour, 1000)。每例同时跑"整喂"与"逐码点切 feed"两式，
> 逐格记录 text 十六进制转储与 ZzCellWidth 枚举值。实测于 T1 修复波之后
> （基线 45/45）。本表是 T3 putChar 聚簇集成的唯一实现依据；表与计划伪码
> 冲突时以本表为准。

## 宽度枚举对照

- w1 = ZzCellWidth::Narrow（窄格，占 1 列）
- w2 = ZzCellWidth::WideLead（宽格首格，占 2 列）
- w3 = ZzCellWidth::WideContinuation（宽格续格，无文本占位）

## 探针实测记录

### 基本 15 例

**01 单组合符 a + U+0301**——两式一致。1 格：`c0` w1，文本：

```
61 CC 81
```

光标 (0,1)：组合符续接不推进光标。

**02 双组合符 e + U+0301 + U+0327**——两式一致。1 格：`c0` w1，文本：

```
65 CC 81 CC A7
```

**03 Emoji ZWJ 对（👨‍👩）**——两式一致。2 格：`c0` w2 + `c1` w3，`c0` 文本：

```
F0 9F 91 A8 E2 80 8D F0 9F 91 A9
```

光标 (0,2)。

**04 家庭 ZWJ 四连（👨‍👩‍👧）**——两式一致。2 格：`c0` w2 + `c1` w3，整串 11 字节入一格。

**05 区旗单发 U+1F1FA**——两式一致。2 格：`c0` w2 + `c1` w3。注意：**单个 RI 即判宽 2**，非成对才宽。

**06 区旗成对 US**——两式一致。2 格：`c0` w2（两个 RI 码点同格）+ `c1` w3。

**07 区旗三连**——两式一致。4 格：`c0` w2（RI 对）+ `c1` w3 + `c2` w2（落单 RI）+ `c3` w3。GB12/13 成对语义正确。

**08 VS16 变宽 U+261D + U+FE0F**——两式一致。2 格：`c0` w2 + `c1` w3，`c0` 文本：

```
E2 98 9D EF B8 8F
```

**09 VS16 红心 U+2764 + U+FE0F**——两式一致。2 格：`c0` w2 + `c1` w3。

**10 VS15 变窄 U+2764 + U+FE0E**——两式一致。1 格：`c0` w1。VS15 保持窄。

**11 keycap 1 + U+FE0F + U+20E3**——两式一致。2 格：`c0` w2 + `c1` w3，`c0` 文本：

```
31 EF B8 8F E2 83 A3
```

**12 InCB 连字（क + ् + ष）**——两式一致。2 格：`c0` w2 + `c1` w3。注意：**基字符 क 为窄，连字聚簇判宽 2**。

**13 CJK + 组合符（中 + U+0301）**——两式一致。2 格：`c0` w2 + `c1` w3，`c0` 文本：

```
E4 B8 AD CC 81
```

宽格对上续接，宽度不变。

**14 a + ZWJ + 👩（ZWJ 前非 ExtPic）**——两式一致。3 格：`c0` w1（a + ZWJ 聚簇，文本 61 E2 80 8D）+ `c1` w2（👩 独立宽格）+ `c2` w3。GB9 使 ZWJ 并入前格、GB11 不命中使 emoji 断开，与 UAX 预期完全一致。

**15a Prepend 单发 U+0600**——两式一致。1 格：`c0` w1。

**15b Prepend + 字母 U+0600 + a**——**两式不一致**（不规则 I-2，见末节）：

- 整喂：2 格，`c0` w2（D8 80 61 同格聚簇）+ `c1` w3——GB9b 聚簇成功但宽度判 2；
- 切 feed：2 格，`c0` w1（D8 80）+ `c1` w1（61）——跨 feed 聚簇失败，断成两个窄格。

### 边界用例

**B1 79 个 a + U+0301（软换行边界续接）**——**两式不一致**（不规则 I-1，见末节）。79 个 a 填满 `c0` 至 `c78`，光标 (0,79)，无 wrap-pending：

- 整喂：U+0301 附到 **`c0`**（文本 61 CC 81），`c1` 至 `c78` 为纯 a——附错位；
- 切 feed：U+0301 附到 **`c78`**（光标左邻格）——符合"续接并入前格"预期。

两式光标均停在 (0,79)，均不换行，row 1 为空。

**B2 78 个 a + 中 + U+0301（宽格对上的续接）**——两式一致。中占 `c78` w2 + `c79` w3（行满，wrap-pending）；U+0301 续到宽格对首格 `c78`（文本 E4 B8 AD CC 81），光标随即换行至 (1,0)。即 wrap-pending 状态下续接码点落上一行尾宽格对，光标执行换行。

**B3 a + U+261D + U+FE0F + bc（VS16 窄变宽位移语义）**——两式一致。布局：`c0` w1（a）+ `c1` w2（☝+VS16 聚簇）+ `c2` w3（**原位插入的续格**）+ `c3` w1（b）+ `c4` w1（c），光标 (0,5)。裁定：基字符已按窄格落格后，VS16 续接使其**原位变宽**——该格转 WideLead，右侧插入 WideContinuation 续格，其后的输入整体右移一格。

**B4 79 个 a + U+261D + U+FE0F（尾列窄变宽）**——两式一致。U+261D 落 `c79`（行满，wrap-pending）；VS16 续接后 `c79` **保持 w1**（聚簇 E2 98 9D EF B8 8F 窄格不变宽，尾列无续格空间时变宽被抑制），光标换行至 (1,0)。

### SGR 画笔属性补探（T2 修复波 Major 1，计划显式委托 T2 实测的决策点）

记号：`I1` / `I2` / `I3` 为 Indexed 前景色（红 / 绿 / 黄），`a0000` 为属性位原始值（无样式）。

**SGR1 红 a + 换绿 + U+0301**——两式一致。1 格：`c0` w1，文本 61 CC 81，画笔 **I1（红）**。裁定：换绿画笔后喂入的组合符续接到基格，**整格保留基格原画笔（红），新画笔（绿）被忽略**。

**SGR2 红 a ☝ + 绿 VS16 + 黄 bc（原位变宽的画笔归属）**——两式一致。布局：`c0` w1 I1（a）+ `c1` w2 I1（☝+VS16 聚簇）+ `c2` w3 I1（插入续格）+ `c3` w1 I3（b）+ `c4` w1 I3（c）。裁定：原位变宽时被变宽格与插入续格均**保留基格原画笔（红）**，VS16 带入的绿画笔被忽略；其后的 b / c 用各自落格时的画笔（黄）。

**SGR3 红 👨 + 绿 ZWJ + 👩**——两式一致。2 格：`c0` w2 I1（整串 ZWJ 聚簇）+ `c1` w3 I1。裁定：ZWJ 序列续接同样**整格保留基字符画笔（红）**，续接码点带入的新画笔不生效。

### 组合盲区补探（T2 修复波 Nit 1 授权，只探不判）

**N1 RI + 组合符（U+1F1FA + U+0301）**——两式一致。2 格：`c0` w2 + `c1` w3，`c0` 文本：

```
F0 9F 87 BA CC 81
```

**N2 宽基 + VS16（中 + U+FE0F）**——两式一致。2 格：`c0` w2 + `c1` w3（已宽基加 VS16 保持宽）。

**N3 裸 keycap（1 + U+20E3，无 VS16）**——两式一致。1 格：`c0` w1，文本：

```
31 E2 83 A3
```

注意：无 VS16 时 keycap 聚簇判**窄**（对照例 11 带 VS16 判宽）。

**N4 ExtPic + 肤色（👍 + 🏽，U+1F44D + U+1F3FD）**——两式一致。2 格：`c0` w2 + `c1` w3（肤色修饰符并入基格，宽 2）。

## 裁定结论（T3 实现依据）

### 1. 聚簇宽度规则

- 宽 2（WideLead + WideContinuation）：emoji ZWJ 序列（例 03/04）、ExtPic + VS16（例 08/09）、keycap（例 11，须带 VS16——N3 实测裸 keycap 无 VS16 判窄）、RI 区旗——**单发即宽**（例 05/06/07）、InCB 连字（例 12，基字符窄也判宽）、宽基 + 组合符（例 13，保持基宽）、ExtPic + 肤色修饰符（N4）、RI + 组合符（N1）、宽基 + VS16（N2，保持宽）、Prepend + a 整喂聚簇（例 15b 整喂，不规则，native 目标见 §5c）。
- 窄 1（基字符宽度）：窄基 + 任意组合符序列（例 01/02）、ExtPic + VS15（例 10）、a + ZWJ 聚簇（例 14 的断开侧）、Prepend 单发（例 15a）。
- 续接不推进光标（例 01 光标 (0,1)）。
- 可供 T3 归约的形态：聚簇含 emoji 表现（ZWJ 序列 / VS16 / keycap / RI / InCB 连字）→ 宽 2；否则保持基字符原宽。InCB 连字判宽与 RI 单发判宽是 contour 实测裁定，T3 须按表对齐，不得按"基宽"自推。

### 2. VS16 窄变宽位移语义（T3 最难语义点，逐字钉死）

- 行内有续格空间（B3）：基字符窄格**原位**转 WideLead，右侧**插入** WideContinuation 续格，光标与其后的输入**右移一格**（b 落 `c3`）。不是丢弃、不是覆盖右格。
- 行末列无续格空间（B4）：变宽**被抑制**，聚簇保持 w1 落尾列，光标换行。contour 不把尾列聚簇变宽、也不把内容挤到下一行。

### 3. 软换行边界续接语义

- 光标在末列、无 wrap-pending（B1 切 feed）：组合符续到光标左邻格（`c78`），不换行。即**行尾格可以被下一码点续接**。
- wrap-pending（宽格对占满行尾，B2）：组合符续到宽格对首格，光标随即换行 (1,0)。续接目标是物理上行尾格，换行在续接之后发生。

### 4. a + ZWJ + emoji 断开行为

a 与 ZWJ 聚簇（GB9，窄格），emoji 断开独立宽格（GB11 不命中）——contour 行为与 UAX 完全一致，native 按 zzGraphemeContinues 判定即可天然对齐。

### 5. 跨 feed 切断与整喂一致性

原 19 例（基本 15 例 + 边界 B1 至 B4）中 **17 例两式完全一致、2 例不一致**（T2 修复波独立重跑实测值；逐例记录本身全对，初版总数句"16 一致 3 不一致"为笔误）；修复波新增的 SGR 三例与 N 四例两式均一致。2 例不一致逐条钉住：

- 例 15b（Prepend + a）：整喂聚簇成功（宽 2），切 feed 断成两窄格——contour 跨 feed 对 GB9b 续接缺失。
- 例 B1（79a + U+0301）：整喂组合符附到 `c0`，切 feed 附到 `c78`。
- 其余全部一致（含全部 emoji/VS16/InCB/区旗例与 B2/B3/B4 边界例）。

### 5b. 画笔属性归属（SGR 补探裁定，T3 续接落格的画笔规则）

- 续接码点带入的新画笔（前景色 / 属性）**一律不生效**：续接格、原位变宽格、插入的 WideContinuation 续格均**保留基格（首个码点落格时）的画笔**（SGR1/SGR2/SGR3 三例一致实测）。
- 被右移的后续格保持各自落格时的画笔（SGR2 的 b / c 为黄）。
- T3 实现：续接落格时 putCell 更新文本但**画笔属性保持前格原值**（与计划伪码的预期一致，实测确认）；原位变宽插入的续格同样取基格画笔。

### 5c. 控制者裁定（T2 修复波并入，T4 compat 断言依据）

- **Prepend + a 宽度**：无 emoji 表现一律基宽——native 目标宽 1；contour 整喂 w2 记为 I-2 不规则行为。T4 compat 按 b 类分歧**分别断言钉住**（contour 整喂 w2 / native w1），不静默剔除。
- **I-1（B1 整喂错附 `c0`）**：同样按 b 类分歧钉住——T4 compat 中 B1 整喂例两后端分别断言（contour 附 `c0` / native 附当前行尾格 `c78`）；切 feed 式正常对齐。

### 6. 不规则行为清单（libunicode 边角，逐条留痕）

- **I-1（B1 整喂错位）**：整缓冲喂入时 U+0301 附到行首 `c0` 而非光标左邻格 `c78`，疑似 libunicode 整缓冲处理下"前格"定位缺陷；切 feed 行为正确。T3 按切 feed 语义（续到光标左邻格）实现，整喂差异作为 contour 已知缺陷记录，不作为 parity 目标。
- **I-2（例 15b Prepend）**：跨 feed 聚簇缺失（两式分歧），且整喂聚簇宽 2 的裁定孤立（Prepend 单发 w1）。控制者裁定（见 §5c）：native 按"无 emoji 表现一律基宽"取 w1，contour 整喂 w2 作为本不规则项留痕，T4 compat 按 b 类分歧分别断言。
- **I-3（RI 单发宽 2）**：单个 RI 未配对也占 2 列。
- **I-4（InCB 连字宽 2）**：窄基连字聚簇判宽 2，非基宽。
- **I-5（B4 尾列变宽抑制）**：尾列 VS16 聚簇保持窄，与行内变宽（B3）语义不同，属边界特判。
